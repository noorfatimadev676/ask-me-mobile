# Ask-Me Mobile

A responsive multi-page mobile phone guide and comparison website built using HTML, CSS, Bootstrap, and JavaScript.

## About the Project

Ask-Me Mobile is a frontend website designed to help users explore mobile phones, view phone information, compare different devices, and browse related content through a clean and responsive interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Features

- Responsive navigation
- Mobile phone information pages
- Phone comparison
- FAQ section
- Contact page
- Review section
- Team section
- Responsive user interface
- Multiple mobile phone detail pages

## Project Purpose

This project was created as a frontend web development project to practice responsive web design, page layouts, navigation, JavaScript functionality, and user-friendly interfaces.

## Project Type

Frontend Web Development Project
